Overview

The question

Each row is a film with its budget, gross revenue, rating, genre, score, votes, director, star, company and more. The question was which of these move together with gross revenue, including whether the production company matters.

Step 1

Load the data and check for gaps

What the code does: reads the CSV, then prints the share of missing values in every column.

import pandas as pd
import numpy as np
import seaborn as sns
import matplotlib.pyplot as plt

df = pd.read_csv('movies.csv')

for col in df.columns:
    pct_missing = np.mean(df[col].isnull())
    print(f'{col} - {pct_missing:.1%}')

Budget was the big gap: about 28% of films had no budget. Every other column was close to complete.

2026 review: the original printed the fraction (0.283) with a % sign after it. The format above shows it as a real percentage.

Step 2

Fix the release year

Why: to get the year each film was actually released from the released date. What the code does: pulls the four-digit year out of that text.

df['year_correct'] = df['released'].str.extract(r'(\d{4})')

2026 review: the original took the first four characters of released. Because dates look like "June 13, 1980 (United States)", that produced the month name instead of the year. Extracting the four-digit number fixes it.

Step 3

Plot budget against gross revenue

What the code does: a seaborn regression plot shows each film as a point with a best-fit line.

sns.regplot(x='budget', y='gross', data=df,
            scatter_kws={'color': 'red'}, line_kws={'color': 'blue'})
Step 4

Correlation matrix

What the code does: calculates the Pearson correlation between every pair of numeric columns and draws it as a heatmap.

correlation_matrix = df.corr(method='pearson', numeric_only=True)
sns.heatmap(correlation_matrix, annot=True)
plt.title('Correlation Matrix for Numeric Features')
plt.show()
Step 5

Does the production company matter?

What the original code did: turned text columns like company and genre into category codes and added them to the correlation matrix. Company came out near zero.

2026 review: category codes are just alphabetical numbers, so that test can't measure anything. I replaced it with a comparison of average gross for the ten companies with the most films.

top = df['company'].value_counts().head(10).index
(df[df['company'].isin(top)]
   .groupby('company')['gross'].agg(['count', 'mean'])
   .sort_values('mean', ascending=False))

The averages range from about $60M (TriStar Pictures) to about $295M (Walt Disney Pictures), so company does matter on average. Big studios also spend more, so budget explains part of that gap.

Results

What I found and learned

Budget had the strongest relationship with gross revenue (0.74), followed by the number of votes (0.63). Production company matters more than the original version suggested once it is measured properly. About a quarter of films had no budget, and correlation only shows that two things move together, not that one causes the other.

What I learned

  • How to load and inspect a dataset in pandas and check how much is missing.
  • How to plot relationships with matplotlib and seaborn.
  • How to read a correlation matrix, and that correlation is not causation.
  • Looking back: check how a test works before trusting its result. The category-code test said company didn't matter, and it did.
