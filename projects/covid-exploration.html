Overview

The questions

Two tables, one for cases and deaths and one for vaccinations, both by country and date. I wanted to answer: how likely was death after infection, what share of each population was infected, which countries and continents had the most deaths, and how quickly were people vaccinated.

The data has rows for whole continents mixed in with countries. Those rows have a blank continent, so most queries filter them out.

Step 1

Death rate among cases

What the code does: divides total deaths by total cases for each day, shown here for Canada.

SELECT location, date, total_cases, total_deaths,
       (total_deaths / total_cases) * 100 AS DeathPercentage
FROM PortfolioProject1.dbo.CovidDeaths
WHERE location LIKE '%canada%' AND continent IS NOT NULL
ORDER BY 1, 2;
Step 2

Share of the population infected

What the code does: divides total cases by population, then finds each country's highest value.

SELECT location, population,
       MAX(total_cases) AS HighestInfectionCount,
       MAX(total_cases / population) * 100 AS PopulationInfectedPercentage
FROM PortfolioProject1.dbo.CovidDeaths
GROUP BY location, population
ORDER BY PopulationInfectedPercentage DESC;
Step 3

Deaths by country and continent

What the code does: takes the highest running death total for each country, then for each continent. total_deaths was stored as text, so it is cast to a number first or the sort comes out wrong.

SELECT continent, MAX(CAST(total_deaths AS INT)) AS TotalDeathCount
FROM PortfolioProject1.dbo.CovidDeaths
WHERE NOT continent = ''
GROUP BY continent
ORDER BY TotalDeathCount DESC;
Step 4

Global totals

What the code does: adds up daily new cases and deaths across all countries to get one global death rate. These are the figures shown at the top of the dashboard.

SELECT SUM(new_cases) AS total_cases,
       SUM(CAST(new_deaths AS INT)) AS total_deaths,
       SUM(CAST(new_deaths AS INT)) / SUM(new_cases) * 100 AS DeathPercentage
FROM PortfolioProject1.dbo.CovidDeaths
WHERE NOT continent = '';
Step 5

Rolling vaccinations with a window function

What the code does: joins deaths to vaccinations on country and date, then uses SUM ... OVER (PARTITION BY ...) to keep a running total of vaccinations for each country.

SELECT dea.continent, dea.location, dea.date, dea.population, vac.new_vaccinations,
       SUM(CONVERT(BIGINT, vac.new_vaccinations))
         OVER (PARTITION BY dea.location ORDER BY dea.location, dea.date) AS RollingPeopleVaccinated
FROM PortfolioProject1.dbo.CovidDeaths dea
JOIN PortfolioProject1.dbo.CovidVaccinations vac
  ON dea.location = vac.location AND dea.date = vac.date
WHERE NOT dea.continent = ''
ORDER BY 2, 3;
Step 6

Percent vaccinated with a CTE and a temp table

Why: SQL won't let you use a column alias you just created in the same SELECT, so the running total can't be divided by population directly. What the code does: wraps the query in a CTE, then divides in the outer query. The script also builds the same result as a temp table.

WITH PopVsVac (Continent, Location, Date, Population, New_Vaccinations, RollingPeopleVaccinated) AS (
  SELECT dea.continent, dea.location, dea.date, dea.population, vac.new_vaccinations,
         SUM(CONVERT(BIGINT, vac.new_vaccinations))
           OVER (PARTITION BY dea.location ORDER BY dea.location, dea.date)
  FROM PortfolioProject1.dbo.CovidDeaths dea
  JOIN PortfolioProject1.dbo.CovidVaccinations vac ON dea.location = vac.location AND dea.date = vac.date
  WHERE NOT dea.continent = ''
)
SELECT *, (RollingPeopleVaccinated / Population) * 100 AS PercentVaccinated
FROM PopVsVac;
Step 7

Save a view for the dashboard

What the code does: stores the rolling vaccination query as a view, so a visualization tool can read it like a table.

CREATE VIEW PercentPopulationVaccinated AS
SELECT dea.continent, dea.location, dea.date, dea.population, vac.new_vaccinations,
       SUM(CONVERT(BIGINT, vac.new_vaccinations))
         OVER (PARTITION BY dea.location ORDER BY dea.location, dea.date) AS RollingPeopleVaccinated
FROM PortfolioProject1.dbo.CovidDeaths dea
JOIN PortfolioProject1.dbo.CovidVaccinations vac ON dea.location = vac.location AND dea.date = vac.date
WHERE NOT dea.continent = '';

Outcome

Results

The dataset runs from January 2020 to August 24, 2022. Over that period there were about 597 million recorded cases and 6.44 million deaths, a death rate of about 1.08% among recorded cases. Europe had the highest death count of any continent. These results feed the Tableau dashboard.

What I learned

  • How to filter and summarize large tables with WHERE, GROUP BY, MAX and SUM.
  • Why data types matter: numbers stored as text sort wrong until you CAST them.
  • How to join two tables on more than one column (country and date).
  • How window functions keep a running total without collapsing the rows.
  • The difference between a CTE, a temp table and a view, and why a view is handy for feeding a dashboard.
