Overview

Why build it

Sometimes the data you need doesn't exist as a download. This project collects it: once a day, the script reads the product's title and price and adds a dated row to a CSV, so the history builds up on its own.

Step 1

Request the page

Code shortened here; the full version is on GitHub. What the code does: sends a request with browser-like headers (Amazon blocks requests that don't look like a browser) and parses the HTML with BeautifulSoup.

from bs4 import BeautifulSoup
import requests

URL = 'https://www.amazon.com/dp/B08YJ3W1HB'
headers = {'User-Agent': 'Mozilla/5.0 (Macintosh; Intel Mac OS X 10_15_7) ...',
           'Accept-Language': 'en-US,en;q=0.9'}

page = requests.get(URL, headers=headers)
soup = BeautifulSoup(page.content, 'html.parser')
Step 2

Pull out the title and price

What the code does: finds the elements by their HTML id and strips the extra whitespace.

title = soup.find(id='productTitle').get_text().strip()
price = soup.find(id='corePrice_feature_div').get_text().strip()

2026 review: the original cut the price out of a longer string by character position ([16:-247]), which breaks as soon as Amazon changes the page. Reading the price element directly is sturdier.

Step 3

Save each run to a CSV

What the code does: writes a header row once, then appends the title, price and today's date on every run.

import csv, datetime

today = datetime.date.today()
with open('AmazonWebScrapingDataset.csv', 'a+', newline='', encoding='UTF8') as f:
    csv.writer(f).writerow([title, price, today])
Step 4

Run it once a day

What the code does: wraps the steps in a check_price() function and calls it every 86,400 seconds (24 hours).

import time

while True:
    check_price()
    time.sleep(86400)
Results

Output and what I learned

A run on October 30, 2026 added this row to the CSV:

TitlePriceDate
Bang & Olufsen Beoplay HX Over-Ear Headphones - TimberCAD 1,046.042026-10-30

Each daily run adds one more row, so the file becomes a price history. Amazon showed the price in Canadian dollars because the script ran from Canada.

What I learned

  • How to request a web page and pull data out of the HTML with BeautifulSoup.
  • How to clean scraped text and save it with a date to a CSV.
  • How to automate a script with a loop and a timer.
  • Scrapers are fragile: sites change their layout and block automated requests, so they need checking.
