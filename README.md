# justinlawlor.github.io

Portfolio site for Justin Lawlor, business systems analyst.

Plain HTML, CSS and JavaScript, published with GitHub Pages (see `.github/workflows/deploy.yml`).

## Adding a project
1. Copy an existing page in `projects/` (for example `nashville-housing.html`) to `projects/<slug>.html` and replace the content.
2. Add an entry to `assets/js/projects.js`. The project cards and filters update automatically.

## Editing the menu
Tabs live in the `NAV` list at the top of `assets/js/site.js`.
